# RCGP: Computers in Primary Care (1980)

[Original PDF scan](computers-in-primary-care.pdf) and [Markdown OCR transcript](transcript.md) of *Computers in Primary Care: Report of the Computer Working Party*. Royal College of General Practitioners, Occasional Paper 13, June 1980. ISBN 0-85084-073-2. Both files are part of this archive. The [PubMed Central record](https://pmc.ncbi.nlm.nih.gov/articles/PMC2573752/) is retained for provenance only.

Chapter 1 lists desirable attributes of a general practice record system. Chapter 3 proposes a phased computerised practice system. This is historical professional guidance, not an NHS procurement specification.
