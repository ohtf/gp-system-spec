# Security policy

Report exposed credentials, personal data or other sensitive material privately to [security@openhealthtechnology.org](mailto:security@openhealthtechnology.org). Include the affected path or commit hash, but do not paste the sensitive material into the report or open a public issue. See the [OHTF security policy](https://openhealthtechnology.org/community/security/) for reporting and disclosure details.

For copyright removal requests, see the [README](README.md#copyright-and-removal-requests).
