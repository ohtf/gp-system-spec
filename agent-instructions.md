# Agent instructions

Read [README.md](README.md), [snapshots.md](snapshots.md), the relevant collection README and [house style](https://github.com/pacharanero/house-style/blob/main/AGENTS.md). This is a historical archive, not clinical software or a conformance authority.

- Preserve original files, notices, source URLs and edition or capture dates. Do not edit evidence to modernise it. Put interpretation beside it.
- Keep jurisdictions, editions and informal proposals separate. Do not add raw captures or large excluded files to Git without reviewing their contents and rights.
- Run `s/test`, `s/scrape --validate` for mirror layout changes, and `git diff --check` before committing. The Zensical configuration intentionally previews only the NHS collection.
- Commit validated changes locally. Do not configure a remote, push, deploy or publish archive material without approval and rights review. This repository has no hosted CI or protected branch while it remains local.
