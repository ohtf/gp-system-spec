# Tech Innovation Home

### Welcome to the Tech Innovation Framework Capabilities and Standards site

The Tech Innovation Framework includes those Capabilities and Standards within the existing [**GP IT Futures Capabilities and Standards model**](https://nhse-dsic.atlassian.net/wiki/spaces/GPITF), with the following changes:

#### Capabilities

- The Productivity Capability is not applicable for this Framework
- The Medicines Verification Capability is not applicable for this Framework

#### Standards

- The [**Primary Care Technology Innovation Standard**](../../DCSDCS/Digital-Services-for-Integrated-Care-DSIC-Capabilities-Standards-Home/Published-Content/Primary-Care-Technology-Innovation-Standard.md) is mandatory for this Framework
- The National Medicines Verification System Standard is not applicable for this Framework
