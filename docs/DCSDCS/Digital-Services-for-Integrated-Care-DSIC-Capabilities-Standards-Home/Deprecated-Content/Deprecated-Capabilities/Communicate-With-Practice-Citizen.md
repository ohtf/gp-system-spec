# Description

Supports secure and trusted electronic communications between Patients and the Healthcare Organisation. Integrates with [Patient Information Maintenance - GP](../../DSIC-Capabilities/Patient-Information-Maintenance-GP.md) Solution.

# Outcomes

|  |  |
| --- | --- |
| For a Patient: | Accessing support and being able to communicate with their Healthcare Organisation remotely in a manner that suits their lifestyle, and health and care needs. |
| For the Healthcare Organisation: | Provision of flexible tools that support remote communications with a Citizen. This will allow for efficient access to Healthcare Organisation team members, supporting Patient care and safety and protecting Patient confidentiality. |
