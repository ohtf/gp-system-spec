# Description {#RiskStratification-Description}

Supports the performing of Risk Stratification using pre-defined criteria that can be run against Patient data.

# Outcomes {#RiskStratification-Outcomes}

|  |  |
| --- | --- |
| For a Patient: | Patients identified as at risk may receive preventative care. |
| For Primary Care: | Able to proactively identify at-risk Patients. |
