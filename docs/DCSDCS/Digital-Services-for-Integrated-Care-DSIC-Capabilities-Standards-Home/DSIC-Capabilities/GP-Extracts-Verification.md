# Description {#GPExtractsVerification-Description}

Supports Health or Care Professionals to ensure the accuracy of the data extracted from Electronic Patient Records (EPR) via the [General Practice Extraction Service (GPES)](https://digital.nhs.uk/services/general-practice-extraction-service) and sent to the [Calculating Quality Reporting Service (CQRS)](https://welcome.cqrs.nhs.uk/), both operated by NHS Digital.

# Outcomes {#GPExtractsVerification-Outcomes}

|  |  |
| --- | --- |
| For the GP Practice: | Staff can verify that the information to be extracted or that was extracted to support payment is accurate. |

E00430 - Additional Implementation Details {#GPExtractsVerification-E00430-AdditionalImplementationDetails} Solutions MUST comply with the following when implementing this Epic:   - The reports are to match the extraction logic which is being used to generate the national GPES extraction - Reports to be produced for each extract supported by the Solution which is extracted by the GPES Data Extraction service and sent to the Calculating Quality Reporting Service (CQRS) (see [**Current Live Extract Specifications**](https://digital.nhs.uk/data-and-information/information-standards/information-standards-and-data-collections-including-extractions/publications-and-notifications/standards-and-collections/gp-data-collections) section for information on current live extracts) - The reports need to be accessible throughout the duration of the service and then for 6 years from the end of the service. The duration of the service is defined in the appropriate service specification or via the [**GMS contract**](https://www.gov.uk/government/publications/nhs-primary-medical-services-directions-2013) - Each report to be executed for a specific period which matches the period for which data is to be extracted for the national extract (See [**Business Rules**](https://digital.nhs.uk/data-and-information/data-collections-and-data-sets/data-collections/quality-and-outcomes-framework-qof/quality-and-outcome-framework-qof-business-rules/quality-and-outcomes-framework-qof-business-rules-v47.0-2022-2023-baseline-release) {#GPExtractsVerification-E00430-SupportingInformation}  - Future extracts are those which have been certified by GPES and have an associated set of Run Time Parameters. It is the responsibility of the GPES team to provide correct Run Time Parameters to Suppliers (for more information on 'future extracts' and those that have 'extract parameter' values, see [**GPES Data Extraction**](../DSIC-Standards/Non-Overarching-Standards/GPES-Data-Extraction.md)) - Examples of additional Patient identifying details that MAY be displayed include, but are not limited to:    - Patient’s registration status   - Patient's age   - Patient's gender - Further information on claim windows can be found in Paragraph 7.2 part IV of the [**Pneumococcal vaccination specification**](https://www.england.nhs.uk/publication/directed-enhanced-service-specification-seasonal-influenza-and-pneumococcal-polysaccharide-vaccination-programme-2020-21/) |
