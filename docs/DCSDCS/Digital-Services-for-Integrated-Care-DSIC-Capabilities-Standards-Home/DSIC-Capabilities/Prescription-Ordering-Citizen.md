# Description {#PrescriptionOrdering-Citizen-Description}

Enables Patients to request for a Repeat medication recorded in [Prescribing](Prescribing.md) to be issued online.

# Outcomes {#PrescriptionOrdering-Citizen-Outcomes}

|  |  |
| --- | --- |
| For a Patient: | The ability to request a further issue of a Repeat medication without having to attend the Healthcare Organisation. |
| For Primary Care: | Facilitating access to prescribed Repeat medication as per the treatment needs of individual Patients. Reducing the risk of transcription errors, fewer phone calls, fewer face-to-face transactions with Patients and releasing time for staff to be deployed on other tasks. |
