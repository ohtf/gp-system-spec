# Description {#DigitalDictation-Description}

Supports the conversion of speech to unstructured text and the recording of this unstructured text to Patient/Service User’s record.

# Outcomes {#DigitalDictation-Outcomes}

|  |  |
| --- | --- |
| For a Patient/Service User: | Accurate recording to a Patient/Service User's record of information based on Patient/Service User interactions, supporting more accurate and efficient care provision. |
| For Health or Care Organisations: | Time savings and better staff productivity with accuracy and efficiency as part of the process for recording information for Patient/Service User interactions. |
