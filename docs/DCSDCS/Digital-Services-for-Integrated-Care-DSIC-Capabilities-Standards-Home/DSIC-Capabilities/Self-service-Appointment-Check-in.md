# Description

Supports the self-service Appointment check-in process for Patients.

# Outcomes

|  |  |
| --- | --- |
| For a Patient: | Enables the Patient to check in for their Appointment without the need to speak to a Health or Care Professional. |
| For Health or Care Organisations: | Enables Health or Care Organisations to optimise staff capacity by reducing the need for manual Patient check in. |
