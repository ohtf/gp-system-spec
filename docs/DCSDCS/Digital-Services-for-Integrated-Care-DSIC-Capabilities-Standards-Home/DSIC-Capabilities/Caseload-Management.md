# Description

Supports the Health or Care Professional in managing Patient/Service User's Cases and Caseloads.

# Outcomes

|  |  |
| --- | --- |
| For a Health or Care Professional: | The ability to create and manage a collection of Cases and Caseloads for Patients/Service Users. |
| For Health or Care Organisations: | The ability to manage Health or Care Professional resourcing based on Patient/Service User Cases and Caseloads. |
