# Description {#CareNavigation-Description}

Enables Health or Care Professionals to appropriately process and respond to Online Patient Consultations using a pre-configured Care Navigation Workflow.

# Outcomes {#CareNavigation-Outcomes}

|  |  |
| --- | --- |
| For a Patient/Service User: | Consistent user experience of requesting assistance using Online Consultation tools. |
| For Primary Care: | Ability to process Online Consultation requests using pre-configured Workflow.  Enable the Health or Care Organisation to respond to Online Consultations efficiently.  Enable navigating the Online Patient Consultations and Requests to the right Health or Care Professional in a multidisciplinary team. |
| For the wider NHS and social care system: | Enable consistent processing of Online Patient Consultations and Requests. |
