# Online Patient Request

|  |  |
| --- | --- |
| **ID** | C65 |
| **Version** | 2.0.0 |
| **Type** | Capability |
| **Category** | Consultations |
| **Status** | Effective |
| **Effective Date** | 13 May 2026 |
| **Contracting Vehicle(s)** | [Digital Pathways Solution Registry](https://nhse-dsic.atlassian.net/wiki/spaces/DPSR) |

# Description

Enables Patients to make specific types of clinical/non clinical requests online to their Healthcare Organisation.

# Outcomes

|  |  |
| --- | --- |
| For a Patient: | Able to make clinical/non clinical requests to a Healthcare Organisation. |
| For a Patient Representative: | Able to make clinical/non clinical requests to a Healthcare Organisation on behalf of a Patient. |
| For Primary Care: | To help reduce the administrative burden on Healthcare professionals by freeing up time to focus on providing patient care. |
| For the wider NHS and social care system: | Improve efficiency and communication between Patient and Healthcare Organisation by providing an additional mode of communication alongside traditional methods such as the telephone and walk ins. |
