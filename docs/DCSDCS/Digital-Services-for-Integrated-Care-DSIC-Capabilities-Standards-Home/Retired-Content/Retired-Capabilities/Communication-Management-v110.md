# Description {#CommunicationManagementv1.1.0-Description}

Supports the delivery of communications to recipients.

# Outcomes {#CommunicationManagementv1.1.0-Outcomes}

|  |  |
| --- | --- |
| For a Health or Care Organisation: | Ability to manage communications via a central service, reducing administrative burden and costs, as well as informing recipients. |
