# Online Patient/Service User Request V1.0.1

|  |  |
| --- | --- |

| **Version** | 1.0.1 |

| **Category** | Consultations |
| **Status** | Retired |
| **Effective Date** | 09 Jul 2024 |
| **Contracting Vehicle(s)** | TBC |

# Description

Enables Patients/Service Users to make specific types of clinical/non clinical requests online to their Healthcare Organisation.

# Outcomes

|  |  |
| --- | --- |
| For a Patient: | Able to make clinical/non clinical requests to a Healthcare Organisation. |
| For Primary Care: | To help reduce the administrative burden on Healthcare professionals by freeing up time to focus on providing patient care. |
| For the wider NHS and social care system: | Improve efficiency and communication between Patient/Service User and Healthcare Organisation by providing an additional mode of communication alongside traditional methods such as the telephone and walk ins. |
