# Document Management v1.0.0

|  |  |
| --- | --- |
| ID | C9 |
| Version | 1.0.0 |
| Type | Capability |
| Status | Retired |
| Effective Date | 01 Apr 2019 |

Full Capability status only. For this Capability, Solutions are required to meet all MUST EPICs and associated acceptance criteria.

# Description

Supports the secure management and classification of all forms unstructured electronic documents including those created by scanning paper documents. Also enables processing of documents and matching documents with Patients.

# Outcomes

|  |  |
| --- | --- |
| For General Practice: | Providing functionality that supports the classification and storage of unstructured electronic documents (e.g. Word or PDF documents) either within electronic Patient Records or within a document library to reduce organisational and administrative overheads associated with document management. |
| For the wider NHS and social care system: | Supporting standard classification systems to enable the use of automated and semi-automated processes for handling documents, increasing data security and reducing the burden of manual administrative processes. |
