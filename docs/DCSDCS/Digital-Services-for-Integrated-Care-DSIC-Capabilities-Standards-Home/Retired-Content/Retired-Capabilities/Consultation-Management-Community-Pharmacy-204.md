# Consultation Management - Community Pharmacy 2.0.4

|  |  |
| --- | --- |
| **ID** | C68 |
| **Version** | 2.0.4 |
| **Type** | Capability |
| **Category** | Consultations |
| **Status** | Retired |
| **Effective Date** | 20 Oct 2025 |
| **Contracting Vehicle(s)** | [Community Pharmacy Clinical Services](../../DSIC-Standards/Supplementary-Care-Standards/Community-Pharmacy-Clinical-Services.md) |

# Description

Enables Health or Care Professionals to record Community Pharmacy Consultation Information for Patients and submit this Consultation Information to the Patient’s registered GP Practice and the NHSBSA.

# Outcomes

|  |  |
| --- | --- |
| For a Patient: | There is a detailed and standardised history of consultations recorded and submitted to their registered GP Practice. |
| For Community Pharmacy Clinical Services: | Management of Consultations with technology provides better efficiency to the Organisation by using mechanisms to record and inform other Health or Care Organisations. |
