| **Contracting Vehicle(s)** | TBC |

# Description {#CareNavigationv1.0.1-Description}

Enables Health or Care Professionals to appropriately process and respond to Online Patient/Service User Consultations using a pre-configured Care Navigation Workflow.

# Outcomes {#CareNavigationv1.0.1-Outcomes}

|  |  |
| --- | --- |
| For a Patient/Service User: | Consistent user experience of requesting assistance using Online Consultation tools. |
| For Primary Care: | Ability to process Online Consultation requests using pre-configured Workflow.  Enable the Health or Care Organisation to respond to Online Consultations efficiently.  Enable navigating the Online Patient/Service User Consultations and Requests to the right Health or Care Professional in a multidisciplinary team. |
| For the wider NHS and social care system: | Enable consistent processing of Online Patient/Service User Consultations and Requests. |

Supporting Information {#CareNavigationv1.0.1-E00549-SupportingInformation}  - A Care Navigation Workflow can be described as:    - A pre-configured pathway of events to be completed by one or more Health or Care Professionals or Organisations, to process an episode of care. It MAY include some or all the following and more:      - Receive structured or semi-structured request from Patient/Service User     - Filter the information manually or based on predefined rules     - Ability to refer or signpost the request to different services or appropriate Health or Care Professionals either manually or based on predefined rules     - Assessment of the request either by a human or system based on predefined rules or automated tool   - These Workflows can be manual or automated or a mix of both - Examples of configuring a Care Navigation Workflow MAY include, but are not limited to:    - Create a new Care Navigation Workflow   - Amend an existing Care Navigation Workflow - Examples of details of a Care Navigation Workflow MAY include, but are not limited to:    - Tasks involved in a Care Navigation Workflow   - Decision points in a Care Navigation Workflow   - Various actors/resources involved in a Care Navigation Workflow   - Routing of Online Consultation requests to specific team or roles  ---  E00550 - process Online Consultation requests using Care Navigation Workflow {#CareNavigationv1.0.1-E00550-processOnlineConsultationrequestsusingCareNavigationWorkflow} As a Health or Care Professional  I want to process Online Consultation requests using the configured Care Navigation Workflows  So that the Online Consultation requests are directed to the appropriate Health or Care Professional or service Acceptance criterion 1: process Online Consultation requests using Care Navigation Workflow {#CareNavigationv1.0.1-Acceptancecriterion1:processOnlineConsultationrequestsusingCareNavigationWorkflow} Given a Care Navigation Workflow has been configured  When an Online Consultation request is created by or on behalf of a Patient/Service User  Then the Online Consultation request is processed as per the configured Care Navigation Workflow |
