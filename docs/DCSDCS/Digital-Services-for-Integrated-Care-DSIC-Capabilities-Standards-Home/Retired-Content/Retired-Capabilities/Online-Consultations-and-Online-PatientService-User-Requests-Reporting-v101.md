# Online Consultations and Online Patient/Service User Requests Reporting v1.0.1

# Description

Enables reporting and analysis using a range of Online Consultations and Online Patient/Service User Request data items to support clinical care and Health or Care Organisation management. Also supports submission of data to the Authority to support understanding of demand and activity within Healthcare Organisations.

# Outcomes

|  |  |
| --- | --- |
| For Primary Care: | Have the tools to be able to analyse Online Consultation and Online Patient/Service User Request data locally, which will support areas such as clinical care, audit and operational needs. |
| For the wider NHS and social care system: | Able to use Management Information (MI) about Online Consultations and Online Patient/Service User Requests to improve services and access to information. |
