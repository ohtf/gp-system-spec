# Description {#DocumentManagementv1.0.3-Description}

Supports the secure management of all forms of unstructured electronic documents including those created by scanning paper documents. Also enables processing of documents and matching documents with Patients/Service Users.

# Outcomes {#DocumentManagementv1.0.3-Outcomes}

|  |  |
| --- | --- |
| For Health or Care Organisation: | Providing functionality that supports the storage of unstructured electronic documents (e.g. .DOCX or .PDF documents) to reduce organisational and administrative overheads associated with document management. |
| For the wider NHS and social care system: | Enables the use of automated and semi-automated processes for handling documents, increasing data security and reducing the burden of manual administrative processes. |
