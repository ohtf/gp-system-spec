# Requirements {#UnstructuredDataExtraction-Standardv1.0.0-Requirements}

| Epic Mapping | Requirement ID | Requirement Text | Level |
| --- | --- | --- | --- |
| Epic 1, Epic 2 | **GP-09.1-01** | **Document Classification**  Configure document classification using:   - Correspondence Care Setting Type - Correspondence Document Type - Clinical/non-clinical flag/status | MUST |
| Epic 1, Epic 2, Epic 3 | **GP-09.1-10** | **Document Configuration - Document properties**  Record and update document properties (header file / document metadata)   - Automatically from interpretation of data associated with an electronically received document - User confirmation required before properties are saved - Manually | MUST |
| Epic 1, Epic 2 | **GP-DM-4.2-04** | **Assignation/categorisation - Automatically recording attributes**  Automatically (using document properties, classification and/or content) ascertain and record characteristics/attributes such as document type, category and source, according to locally defined configuration - User confirmation required before characteristics or attributes are saved. | MUST |
| Epic 1, Epic 2 | **GP-DM-4.4-20** | **Viewing and managing documents - Associated coded entries**  Generate associated coded clinical entries and store in the Patient’s Record   - Manually code from review of a document - Manually record values associated with a code - Automatically code from detail within document properties (header file / document metadata) and/or content of a document - User confirmation required before coding is saved | MUST |

# Capability {#UnstructuredDataExtraction-Standardv1.0.0-Capability}

**Applicable Capability**

All supplier Solutions will need to meet this Standard if they are delivering the Unstructured Data Extraction Capability
