# Implementation reference

Browse the [31 July 2026 GP IT Futures implementation reference](implementation-reference/2026-07-31/index.md): 37 capabilities, 471 numbered epics and 886 acceptance criteria. Each epic has its own page, grouped by the publisher's MUST and MAY labels, with the user story, acceptance criteria, implementation notes and links to the original source.

- [Browse capabilities by edition](implementation-reference/2026-07-31/index.md) or search this site by epic ID. IDs can recur across capabilities, so cite the capability ID and version as well as the epic ID.
- [Download the JSON catalogue](implementation-reference/2026-07-31/index.json) for tooling. Its `path` values are URLs relative to the catalogue.
- [Read the captured capability pages](capabilities.md) for the original context and follow any linked standards. The reference includes one S62 appointment-mode rule, not the full set of standards.

This is a historical extract, not a current compliance specification. Source wording remains attributed to NHS England and retains its original rights. See [copyright and removal requests](https://github.com/ohtf/gp-system-spec#copyright-and-removal-requests).
