Description

Enables Patients to request for a Repeat medication recorded in Prescribing to be issued online.

Outcomes

For a Patient:

The ability to request a further issue of a Repeat medication without having to attend the Healthcare Organisation.

For Primary Care:

Facilitating access to prescribed Repeat medication as per the treatment needs of individual Patients. Reducing the risk of transcription errors, fewer phone calls, fewer face-to-face transactions with Patients and releasing time for staff to be deployed on other tasks.

MUST Epics - Describes the minimum functionality required to deliver a Capability. Solutions MUST be successfully evaluated against each Epic and Acceptance Criteria via Capability Assessment in order to be associated with this Capability

E00327 - Patient viewing Repeat medications

As a Patient

I want to view my Repeat medications using Citizen Services

So that I can view the Repeat medications I can request to be issued

Acceptance criterion 1: view Repeat Medications

Given the Patient is enabled for the Prescription Ordering Citizen Service

When the Patient selects to view their Repeat medications

Then the Patient’s Repeat medications are displayed

And the name for each medication is displayed

And the strength for each medication is displayed

And the form for each medication is displayed

And the dose for each medication is displayed

And the date of the most recent issue for each medication is displayed

And the duration for each medication is displayed

E00327 - Additional Implementation Details

Solutions MUST comply with the following when implementing this Epic:

  • Utilise Provider IM1 Patient interface(s) and adhere to IM1 - Interface Mechanism Standard (Patient interface Consumer requirements)

E00327 - Supporting Information

  • Further information on creating Repeat medication can be found in the Prescribing Capability

  • Additional examples of Repeat medication information MAY include, but are not limited to:

    • The suggested date of next issue

    • Date and status of previous request to be issued (with associated free text from Citizen Services requests)

    • Whether the Repeat medication is due for review (including the expected review date where applicable)

Acceptance criterion 3: cancel an outstanding request for a Repeat medication to be issued

Given the Patient is enabled for the Prescription Ordering Citizen Service

When the Patient selects to cancel a request for a Repeat medication to be issued

Then the request is cancelled

E00328 - Additional Implementation Details

Solutions MUST comply with the following when implementing this Epic:

  • Utilise Provider IM1 Patient interface(s) and adhere to IM1 - Interface Mechanism Standard (Patient interface Consumer requirements)

E00328 - Supporting Information

  • Further information on creating Repeat medication can be found in the Prescribing Capability

  • For further information on enabling the Prescription Ordering Citizen Service see manage Prescription Ordering Citizen Service access for a Patient and the Practice in the Patient Information Maintenance - GP Capability

  • Patient MAY be informed of Prescription collection approach upon submission of their request:

    • Notified that the requested Prescription will be sent to the Patient's Electronic Prescription Service (EPS) Nominated Pharmacy (if Patient is participating in EPS)
