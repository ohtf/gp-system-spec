Introduction

The NHS Business Services Authority (NHSBSA) allows Health or Care Organisations to claim payments for services provided.

NHSBSA Claims & Reporting Standard is a series of APIs that provide reporting and claims services.

Requirements

Applicable Suppliers

ID

Requirement

Level

All

NHSBSA01

Implement and maintain the following NHSBSA Manage Your Service (MYS) - Pharmacy APIs inline with the latest specification version:

  • NHSBSA Claim Interface Guide

    • NHS Community Pharmacist Consultation Service (CPCS) API client specification only

  • NHSBSA Contraception API client specification

  • NHSBSA Hypertension Case-Finding API client specification

MUST

Compliance, Assurance and Testing

To achieve NHSBSA Claims & Reporting compliance, Suppliers MUST develop to the service specific APIs, conduct required testing and be able to demonstrate conformance with the requirements of the service API specifications.

For queries on the APIs, please contact mys-platform@nhsbsa.nhs.uk.
