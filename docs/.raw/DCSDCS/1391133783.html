C8E1GP-08.3-02A

External Services - Record request information within Patient Record

Record the following request information within the Patient Record:

  • Unique identifier 
  • Date of request
  • Requestor – Staff Member detail
    • This will include the ability to specify an alternative Staff Member requesting on behalf of a Clinician
  • Type/request item (as a coded clinical term)
  • Reason for the request
  • Sample type
  • Status
  • Laboratory identifier/code
  • Laboratory name

Auto populate data wherever possible (e.g. from data received via the Pathology/Radiology requesting Solution).

Where multiple request items are included within a single request e.g. a number of blood tests, the Solution will record the overall request and the individual detail within.

MUST

C8E1GP-DIAG-04

Reconcile results with requests

Provide ability to reconcile request messages with the resulting reports to update the status of the request to indicate that results are available. Pathology/Radiology Request data items to be available when reconciling are:

  • Unique identifier 
  • Date of request
  • Requestor – Staff Member detail
  • Type/request item (as a coded clinical term)
  • Reason for the request
  • Sample type
  • Status
  • Laboratory identifier/code
  • Laboratory name

Service Requests Reporting

Ability to generate a report based on Patient, Clinician or Practice for Service Requests.

This will be a list of service requests with associated status, by Requestor, by Recipient Target (Service, Organisation and/or Individual) within a date range.
