Description

Enables Patients/Service Users to make specific types of clinical/non clinical requests online to their Healthcare Organisation.

Outcomes

For a Patient:

Able to make clinical/non clinical requests to a Healthcare Organisation.

For Primary Care:

To help reduce the administrative burden on Healthcare professionals by freeing up time to focus on providing patient care.

For the wider NHS and social care system:

Improve efficiency and communication between Patient/Service User and Healthcare Organisation by providing an additional mode of communication alongside traditional methods such as the telephone and walk ins.

E00584 - create an Online Patient/Service User Request

As a Patient/Service User

I want to create an Online Patient/Service User Request

So that I can submit specific types of requests to a Healthcare Organisation at a time and in a way that is convenient for me

Acceptance criterion 1: Patient/Service User creates an Online Patient/Service User Request

Given the Patient/Service Users is permitted to create Online Patient/Service User Requests

When the Patient/Service User selects to create an Online Patient/Service User Request with the Healthcare Organisation

Then the Healthcare Organisation can access the information provided

E00585 - Patient/Service User provides demographic & contact details for an Online Patient/Service User Request

As a Health or Care Professional

I want the Patient/Service User to provide demographic & contact details for an Online Patient/Service User Request

So that the Patient/Service User’s identity is captured and the Online Patient/Service User Request can be processed

Acceptance criterion 1: Patient/Service User provides demographic & contact details

Given Patient/Service Users are permitted to create Online Patient/Service User Requests

When the Patient/Service User selects to create an Online Patient/Service User Request with the Healthcare Organisation

Then the Patient/Service User can provide their demographic & contact details

E00585 - Additional Implementation Details

Solutions MUST comply with the following when implementing this Epic:

  • Patient/Service Users must provide the following demographic and contact details:

    • Name

    • Date of birth

    • Sex

    • Address

    • Mobile/Telephone number

    • Email

E00589 - request fit note

As a Citizen

I want to request a fit note

So that I can provide my employer with evidence of the advice I have been given by my Healthcare Organisation about my fitness to work

Acceptance criterion 1: Patient is 7 days or less off sick

Given Citizens are permitted to request fit note

When the Citizen selects to request a fit note

And the Citizen confirms that the Patient has been sick for less than 7 days

Then the Citizen is signposted for self-certification

Acceptance criterion 2: Patient is more than 7 days off sick

Given Citizens are permitted to request fit notes

When the Citizen selects to request a fit note

And the Citizen indicates that the Patient is going to be sick for more than 7 days

And the Citizen provides the required information

Then the request for a fit note is submitted

E00589 - Additional Implementation Details

Solutions MUST comply with the following when implementing this Epic:

  • Information required from the Citizen in order to request a fit note:

    • What is the Patient’s condition they require the fit note for?

    • Reason for fit note?

    • How long does the Patient/Service User need the fit note for?

E00602 - automatically add SNOMED CT code for Health Review form requests

As a Health or Care Professional

I want an appropriate SNOMED CT code to be automatically recorded when Citizens are requested to complete a Health Review form

So that structured coding can be used for Health Reviews to support categorisation, interoperability and reporting

Acceptance criterion 1: configure Health Review form requests to include SNOMED CT codes

Given the Health or Care Professional is permitted to configure Health Review form requests

When the Health or Care Professional selects to configure a SNOMED CT code for the Health Review form

Then the Health Review form is configured with the SNOMED CT code

Acceptance criterion 2: record SNOMED CT code for Health Review form request

Given the Health Review form is configured with a SNOMED CT code

When the Health or Care Professional selects to submit the Health Review form request to a Citizen

Then the SNOMED CT code is recorded

E00602 - Supporting Information

  • See Data Standards for requirements relating to the implementation of SNOMED CT

  • Examples of configuring Health Review form requests to add a SNOMED CT code MAY include, but are not limited to:

    • Add SNOMED CT code to a Health Review form

    • Amend SNOMED CT code for a Health Review form

    • Delete SNOMED CT code for a Health Review form

    • Enable ability to add SNOMED CT codes to Health Review forms

    • Disable ability to add SNOMED CT codes to Health Review forms

E00603 - automated suggestion of SNOMED CT codes for Health Review form responses

As a Health or Care Professional

I want appropriate SNOMED CT codes to be suggested for Health Review form responses

So that automated assistance is provided in recording the SNOMED CT codes for Health Review form responses

Acceptance criterion 1: define the rules for automatically suggesting a SNOMED CT code for Health Review form responses

Given the Health or Care Professional is permitted to define the rules for automatically suggesting a SNOMED CT code for Health Review form responses

When the Health or Care Professional selects to define a rule for automatically suggesting a SNOMED CT code for Health Review form responses

Then the automated suggestion of SNOMED CT codes rule is defined

Acceptance criterion 2: accept automatically suggested SNOMED CT code for a Health Review form response

Given the Health or Care Professional is permitted to record SNOMED CT codes for Health Review form responses

When the automatically identified SNOMED CT codes are presented to the Health or Care Professional

And the Health or Care Professional selects to accept a suggested SNOMED CT code

Then the accepted SNOMED CT code is recorded for the Health Review form response

Acceptance criterion 3: reject automatically suggested SNOMED CT code for a Health Review form response

Given the Health or Care Professional is permitted to record SNOMED CT codes for Health Review form responses

When the automatically identified SNOMED CT codes are presented to the Health or Care Professional

And the Health or Care Professional selects to reject a suggested SNOMED CT code

Then the rejected SNOMED CT code is not recorded for the Health Review form response
