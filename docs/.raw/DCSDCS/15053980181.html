Description

Enables reporting and analysis using a range of Online Consultations and Online Patient/Service User Request data items to support clinical care and Health or Care Organisation management. Also supports submission of data to the Authority to support understanding of demand and activity within Healthcare Organisations.

Outcomes

For Primary Care:

Have the tools to be able to analyse Online Consultation and Online Patient/Service User Request data locally, which will support areas such as clinical care, audit and operational needs.

For the wider NHS and social care system:

Able to use Management Information (MI) about Online Consultations and Online Patient/Service User Requests to improve services and access to information.

E00577 - report on Online Consultations and Online Patient/Service User Requests

As a Health or Care Professional

I want to have access to reports on Online Consultations and Online Patient/Service User Requests

So that I can make informed decisions

Acceptance criterion 1: report on Online Consultations

Given that there is Online Consultation data available

And the Health or Care Professional is permitted to view Online Consultation reports

When the Health or Care Professional selects to view an Online Consultation report

Then the report results are displayed

Acceptance criterion 2: report on Online Patient/Service User Requests

Given that there is Online Patient/Service User Requests data available

And the Health or Care Professional is permitted to view Online Patient/Service User Request reports 

When the Health or Care Professional selects to view an Online Patient/Service User Requests report

Then the report results are displayed

E00577 - Supporting Information

  • Examples of reports MAY include, but are not limited to:

    • Report on outcomes or dispositions provided to the Patient/Service User

    • Report on the status of Online Consultations and Online Patient/Service User Requests

    • Report on Patient/Service User demographics using the Online Consultation Solution

E00578 - Online Consultations and Online Patient/Service User Requests data collection
