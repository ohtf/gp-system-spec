Description

Enables Patients/Service Users to manage their Personal Health Record information relating to their health and care.

Outcomes

For a Patient/Service User:

Ability to add, view and update their Personal Health Record information about their personal health and care.

MUST Epics - Describes the minimum functionality required to deliver a Capability. Solutions MUST be successfully evaluated against each Epic and Acceptance Criteria via Capability Assessment in order to be associated with this Capability

E00508 - manage Personal Health Record information

As a Patient/Service User

I want to manage my Personal Health Record information

So that my Personal Health Record information is managed

Acceptance criterion 1: record Personal Health Record information

Given the Patient/Service User is permitted to manage their Personal Health Record information

When the Patient/Service User selects to record Personal Health Record information

Then the information is recorded

Acceptance criterion 2: view Personal Health Record information

Given the Patient/Service User is permitted to manage their Personal Health Record information

When the Patient/Service User selects to view their Personal Health Record information

Then the information is displayed

Acceptance criterion 3: amend Personal Health Record information

Given the Patient/Service User is permitted to manage their Personal Health Record information

When the Patient/Service User selects to amend their Personal Health Record information

Then the information is amended

E00508 - Supporting Information

  • Examples of Personal Health Record information MAY include, but are not limited to:

    • Information relating to health conditions (e.g. Crohn's Disease, diabetes or depression)

    • Social care information

    • Insurance information

    • Lifestyle information

MAY Epics - Describes additional functionality associated with the Capability. Suppliers should consider all MAY Epics as part of their User Research. Suppliers can choose to map their Solutions to these Epics and they will be evaluated via Capability Assessment. Contracting Authorities or purchasing organisations may require these Epics as product qualification or requirements criteria

E00509 - create personalised displays for Personal Health Records

As a Patient/Service User

I want to create a personalised display for my Personal Health Record

So that I can view the personalised display of my Personal Health Record

Acceptance criterion 1: create personalised displays for Personal Health Records

Given the Patient/Service User is permitted to manage their Personal Health Record

When the Patient/Service User selects to create a personalised display for their Personal Health Record

Then a personalised display is created

Acceptance criterion 2: view personalised displays for Personal Health Records

Given the Patient/Service User is permitted to manage their Personal Health Record

When the Patient/Service User selects to view a personalised display of their Personal Health Record

Then the Personal Health Record is displayed with the personalised display

E00509 - Supporting Information

  • Examples of personalised displays for a Personal Health Record MAY include, but are not limited to:

    • Reordering the display, for example:

      • Chronologically

      • Based on certain characteristics

    • Filtering data from the Personal Health Record in or out based on certain characteristics or priority

E00510 - enable access to Personal Health Records for Health or Care Professionals

As a Patient/Service User

I want to enable access to my Personal Health Record for Health or Care Professionals

So that my Personal Health Record is accessible to Health or Care Professionals

Acceptance criterion 1: enable access to Personal Health Records for Health or Care Professionals

Given the Patient/Service User is permitted to enable access to their Personal Health Record

When the Patient/Service User selects to enable access to their Personal Health Record for a Health or Care Professional

Then access to the Personal Health Record is enabled for the Health or Care Professional

E00512 - manage external data connections for Personal Health Records

As a Patient/Service User

I want to control which external data connections can import data to my Personal Health Record

So that I can control which external data connections can import data to my Personal Health Record

Acceptance criterion 1: enable external data connections

Given the Patient/Service User is permitted to manage their Personal Health Record

When the Patient/Service User selects to enable an external data connection

Then the external data connection is enabled

And data can be imported into the Personal Health Record from the external data connection

Acceptance criterion 2: disable external data connections

Given the Patient/Service User is permitted to manage their Personal Health Record

When the Patient/Service User selects to disable an external data connection

Then the external data connection is disabled

And data can be imported into the Personal Health Record from the external data connection

E00512 - Supporting Information

  • Examples of external data connections MAY include, but are not limited to:

    • Telehealth devices

    • Telecare devices

  • An example of a Solution which can connect to the Personal Health Record MAY include, but is not limited to:

    • A Clinical System

E00513 - import data to Personal Health Records

As a Patient/Service User

I want to import data to my Personal Health Record

So that I can import data to my Personal Health Record

Acceptance criterion 1: import data into Personal Health Records

Given the Patient/Service User is permitted to manage their Personal Health Record

When the Patient/Service User selects to import data to their Personal Health Record

Then the data is imported to their Personal Health Record

E00513 - Supporting Information

  • Examples of data import formats MAY include, but are not limited to:

    • .XLSX

    • .DOCX

    • .PDF
