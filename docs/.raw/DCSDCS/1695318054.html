GP-03.4-01

Practice and branch site information

Create and maintain information about the Practice and any branch sites, including:

  • Organisation name (legal)
  • Organisation name (business name)
  • ODS code
  • Organisation address
    • Multiple telephone numbers (and associated labels e.g. Branch site x, Appointments, Fax)
    • Multiple email addresses (and associated labels)

Epic 2

GP-03.4-02

Staff Member information

Create and maintain details about each/every individual Staff Member working in or for one or more General Practices, including:

  • Unique identifier
  • Preferred name
  • Gender
  • Role(s) (for/within the Practice)
  • Professional codes and check digit where appropriate, including
    • GMC code
    • NMC code
    • HCPC code
    • RPS code
  • Multiple nationally recognised identification numbers and check digit where appropriate, including
    • GMP code
    • Prescriber identifier
  • Photo ID
  • Start date
  • End date
  • Associated Smartcard (as per Information Governance)
  • Practice Users who do not necessarily use the functionality of the Solution and may or may not have an active Smartcard

Where a Staff Member returns to the General Practice, they will have a record of that period of activity.

GP-03.4-03

Long-term user inactivity periods

Record periods of User activity/inactivity e.g. to accommodate long term leave (such as maternity leave), multiple short term contracts (such as summer administrative staff) or locums.

  • Start date
  • End date
  • Status (available, unavailable (e.g. on leave))

GP-03.4-06

Manage Staff Groups

Support the management of groups (e.g. teams), including:

  • Create staff groups – each group to have a unique name and/or ID
  • Add and remove Staff Members from staff groups
  • Multiple Staff Members to be added to a staff group
  • Staff Members can belong to more than one staff group

Epic 5

GP-03.5-01

Related organisations information

Create and maintain information about related organisations, and their departments (NHS or otherwise), including:

  • Organisation name
  • Organisation type
  • Multiple organisation codes, including ODS code and trading partners identifiers
  • Role(s) (available subset dependent on organisation type)
  • Relationship(s) (between the General Practice and this organisation, indicating the direction of relationship where applicable – available subset dependent on role)
  • Organisation address
  • Multiple telephone numbers (and associated labels e.g. general enquiries, fax)
  • Multiple email addresses (and associated labels)
  • Department details, including
    • Department name
    • Department address
    • Department telephone number(s) and associated labels

Organisation information to be derived from ODS, where available (see GP-03.1-01), and can be supplemented/defined by the General Practice – data items that are common both locally and nationally will be updated from ODS regularly.

Epic 6

GP-03.5-02

Related organisation staff details

Create and maintain staff details about each/every individual working in or for related organisations, including:

  • Full name (including title)
  • Role
  • Multiple nationally recognised identification numbers and check digit where appropriate, including
    • GMC code
    • GMP code
    • NMC code
    • HCPC code
    • Consultant code
  • Link to / association with related organisation, and ability to select department within (this can populate/default contact details)
  • Contact details (telephone, email, fax), and associated category

For guidance on how to obtain Related organisation's Staff Member information see GP-03.1-01

Epic 7GP-RM-1-03

Non-human resources

Create and maintain non-human resources such as rooms, equipment installed in a room and portable equipment.

Create and maintain associations between non-human resources. Associations can be permanent or temporary and can be used to represent existing arrangements of rooms and equipment or to configure potential arrangements. The arrangements will take account of resources that can and cannot be moved.

Temporary associations, especially those using portable equipment, have defined start and end dates and times.
