Introduction

Integration with NHS Notify allows organisations and services to send NHS App messages, emails, texts and letters to Patients, the public and recipients of adult social care.

See NHS Notify for further information.

Requirements

To implement the NHS Notify requirements, you can either use NHS Notify API or NHS Notify MESH. To determine which method of integration is the most appropriate for your Solution, please refer to the ‘Who can use this API’ section in NHS Notify API and the ‘Who can use this integration’ section in NHS Notify MESH.
