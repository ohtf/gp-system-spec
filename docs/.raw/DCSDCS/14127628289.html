Introduction

The Vaccination Extract Standard specifies the flow of vaccination-related information from healthcare settings to the Authority.

Requirements

Applicable Suppliers

ID

Requirement

Level

Suppliers of Solutions which ARE currently deployed into an operational environment, and have implemented NHSE Daily Vaccination Events (In-Bound) Extract.

VE01

Implement and maintain the extraction of vaccination information inline with the latest NHSE Daily Vaccination Events (In-Bound) Extract specification version, and send vaccination event data for vaccines included in the Supported Vaccines list on a daily basis, via the IMMS-API MESH Mailbox.

MUST

  • Suppliers of new Solutions (i.e. those which are NOT currently deployed into an operational environment with existing NHSE Daily Vaccination Events (In-Bound) Extract compliance.

  • Suppliers of Solutions which ARE currently deployed into an operational environment and have implemented the Immunisation FHIR API.

VE02

Implement and maintain the Immunisation FHIR API inline with the latest specification version and send vaccination event data at the time of recording for vaccines included in the Supported Vaccines list.

MUST

Supported Vaccines

The following list outlines the vaccines for which vaccination event data is to be sent to the Authority:

  • BCG

  • COVID-19

  • Hep B

  • Hib/MenC

  • Human Papillomavirus (HPV)

  • Influenza (Flu)

  • Measles, Mumps, Rubella (MMR)

  • Measles, Mumps, Rubella, and Varicella (MMRV)

  • MenACWY

  • MenB

  • Pertussis

  • Pneumococcal

  • Respiratory Syncytial Virus (RSV)

  • Rotavirus

  • Shingles

  • 3 in 1

  • 4 in 1 

  • 6 in 1
