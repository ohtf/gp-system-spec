Full Capability status only. For this Capability, Solutions are required to meet all MUST EPICs and associated acceptance criteria.

Description

Supports recording, reviewing, sending, and reporting of Patient Referrals. Enables Referral information to be included in the Patient Record.


Outcomes

For a Patient:Requests to relevant Health and Care Organisations for advice or handover of care that is efficiently managed, in turn providing better quality of care for the Patient.
For General Practice:Management of Referrals with technology to provide better efficiency to the Practice, by using mechanisms to record and report on Referral information.


MUST Epics - Epics and acceptance criteria will be evaluated during the Capability Assessment Stage of Onboarding

C11E1 - Manage Referrals

As a Practice User

I want to manage Referrals

So that there are Referrals

Acceptance criterion 1: create an e-Referral

Given the Practice User is permitted to create an e-Referral 

When they choose to create an e-Referral 

Then the e-Referral is created

Acceptance criterion 2: create a manual Referral

Given the Practice User is permitted to create a manual Referral 

When they choose to create a manual Referral  

Then a manual Referral is created

Acceptance criterion 3: view a Referral

Given the Practice User is permitted to view Referrals

When they choose to view a Referral

Then the Referral is displayed

Acceptance criterion 4: amend a Referral

Given the Practice User is permitted to amend Referrals

When they choose to amend a Referral

Then the Referral is amended

Acceptance criterion 5: delete a Referral

Given the Practice User is permitted to delete Referrals

When they choose to delete a Referral

Then the Referral is deleted 

C11E2 - view Referral reports

As a Practice User

I want to view Referral reports

So that I see Referral activity

Acceptance criterion 1: view Referral reports

Given the Practice User is permitted to view Referral reports

When the Practice User chooses to view a Referral report

Then the report is displayed
