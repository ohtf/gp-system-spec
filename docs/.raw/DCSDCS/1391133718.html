Description

Enables reporting and analysis using a range of data items to support clinical care and Health or Care Organisation management.

Outcomes

For Health or Care Organisations:

Have the tools to be able to analyse data locally, which will support areas such as clinical care, finance, audit and operational needs.

MUST Epics - Describes the minimum functionality required to deliver a Capability. Solutions MUST be successfully evaluated against each Epic and Acceptance Criteria via Capability Assessment in order to be associated with this Capability.

E00344 - report on a range of data items

As a Health or Care Professional

I want reports to use a range of data items

So that I can run reports based on a range of data items

Acceptance criterion 1: define report criteria

Given the Health or Care Professional is permitted to create reports

When the Health or Care Professional selects to define the criteria for a report

Then the Health or Care Professional can select a range of data items

Acceptance criterion 2: view report results

Given the Health or Care Professional is permitted to view report results

When the Health or Care Professional selects to view the report

Then the report results are displayed

E00344 - Additional Implementation Details

Solutions MUST comply with the following when implementing this Epic:

  • Ability to report on a range of data items provided by achieving compliance with multiple different Capabilities (Data items can be provided by one or more Solutions)

  • Reporting functions to be available between the hours of 8am to 6pm daily, as a minimum

E00344 - Supporting Information

  • Examples of report criteria MAY include, but are not limited to:

    • Any combination of coded or structured data held within or linked to the Patient/Service User Record

    • Historic and future dates or date ranges

    • Defined time periods (e.g. in the last 6 months)

    • Inclusion or exclusion of deceased or inactive Patients/Service Users

    • Data items which are no longer active or are prevented from ongoing use in Patient/Service User Records

  • It is recommended that reporting functions are available at all times when the Solution is available for use

  • It is recommended that data used in reporting is fully up to date to enable decisions to be made without compromising Patient/Service User care

  • For coded data, see Data Standards for requirements

E00345 - include Synthetic Patients/Service Users in reports

As a Health or Care Professional

I want to configure reports to include Synthetic Patients/Service Users

So that I can test reports before they are used operationally

Acceptance criterion 1: include Synthetic Patients/Service Users in reports

Given the Health or Care Professional is permitted to create reports

When the Health or Care Professional selects to include Synthetic Patients/Service Users in the report results

Then Synthetic Patients/Service Users are included in the report results

And any Synthetic Patients/Service Users are indicated in the report results

Acceptance criterion 2: exclude Synthetic Patients/Service Users from reports

Given the Health or Care Professional is permitted to create reports

When the Health or Care Professional selects to exclude Synthetic Patients/Service Users from the report results

Then Synthetic Patients/Service Users are excluded from the report results

E00345 - Supporting Information

  • Synthetic Patients/Service Users are records which can be used by some live processes but which do not relate to any existing person. For further information about Synthetic Data see the Master Glossary
