Introduction

The Patient Flags Service allows Health or Care Professionals to access and update Patient Flags and associated supporting resources.

Requirements

Applicable Suppliers

GP Suppliers

PFS-001

Implement and maintain the Patient Flags Service - FHIR API inline with the latest API specification version for the Patient Flags and associated supporting resources as per the Flag Implementation by Capability Mapping section.

PFS-002

The Patient Flags Service - FHIR API to be called to retrieve the latest Patient Flag information when a notification from the Multicast Notification Service (MNS) is processed.

Dependencies

  • Creating a compliant implementation requires implementing the following dependent interface Standards:

    • Personal Demographics Service (PDS)

    • Multicast Notification Service (MNS)

    • Authentication and Access - using NHS Care Identity Service 2 API (unless Patient Flags Service is implemented using Application-Restricted access)
