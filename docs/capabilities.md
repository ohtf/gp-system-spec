# GP IT Futures capabilities

These are the functions linked from the original [GP IT Futures capability matrix](nhs-snapshot/GPITF/GP-IT-Futures-Capabilities-and-Standards-Home/index.md). The functional pages are filed under DSIC in the NHS source, not under GP IT Futures. Open a capability and start with **Description** and **Outcomes**, then look for the **MUST** and **MAY** epics and their acceptance criteria.

For individual epic pages and a machine-readable catalogue, use the [implementation reference](implementation-reference.md).

Statuses and versions below are as captured on 31 July 2026. An “Effective” label is the status on that captured capability page, not a statement that the GP IT Futures framework is still open. [Read the coverage check](#coverage).

## Coverage

On 19 November 2026, the [publisher’s public GPITF listing](https://nhse-dsic.atlassian.net/wiki/api/v2/spaces/1391133383/pages?limit=100) returned 15 pages. All 15 were present in the July baseline with matching Confluence page IDs and versions. All 37 capability links from the captured GPITF matrix resolve to captured DSIC pages. All have a Description; 36 have numbered epics, and the deprecated Productivity capability has a description but no numbered epics in the source. The set of numbered epic IDs matches the captured source HTML for each capability.

This verifies the public GPITF space and its linked capability pages, not private pages, every historical edition, attachment completeness or the current version of every DSIC page. The [capture omissions](nhs-snapshot/archive-omissions.md) include five webinar recordings. Check the original NHS source before relying on any requirement.
