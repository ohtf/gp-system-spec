# GP system specification archive

An unofficial archive of GP clinical-system requirements over time. Each collection retains its own publisher, jurisdiction, dates and status. The archive is for research and comparison, not a current compliance checklist or a single specification.

| Collection | Coverage |
| --- | --- |
| [RCGP, 1980](rcgp-1980/README.md) | *Computers in Primary Care*, including desirable attributes of a GP record system. Historical UK professional report. |
| [Ireland](ireland/README.md) | *General Practice Software Management Systems: Requirements for Certification 2022*, version 1.5, issued in January 2025. Irish certification requirements. |
| [NHS England GP IT Futures and DSIC](nhs-futures/README.md) | Confluence mirror of capabilities, standards and procurement material, including the successor DSIC standards. |
| [Trello ideas](notes/trello/README.md) | A feature-ideas snapshot. Not a formal requirements source. |

See [the snapshot register](snapshots.md) for what each capture contains and how to retrieve it. Add new sources as separate collections; don't fold requirements from different jurisdictions or dates together.

## Local use

The original PDFs can be read directly. To preview the NHS mirror locally, install `requirements.txt`, then run `zensical serve` from the repository root. Run `s/test` for the scraper's offline tests. See [the NHS mirror instructions](nhs-futures/README.md#maintenance-tooling) before refreshing it.

No remote is configured. The imported documents retain their original rights and notices; see [licensing and archive rights](LICENCE.md) before sharing any material.
