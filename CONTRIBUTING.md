# Contributing

Open an issue for a broken source link, incorrect edition or missing attribution. Do not post credentials, personal data or rights-sensitive files. Use the private route in [SECURITY.md](SECURITY.md) or the [copyright removal process](README.md#copyright-and-removal-requests).

Keep publisher, jurisdiction, edition and capture date distinct. Do not edit archived source files to make them match house style. Add corrections or interpretation beside them.

Run `s/linkcheck` before submitting catalogue changes. For scraper or mirror changes, install `requirements-archive.txt` and run `s/test` and `s/scrape --validate`. Follow the [OHTF Developer Certificate of Origin policy](https://openhealthtechnology.org/community/dco/) and sign off commits with `git commit -s`.
