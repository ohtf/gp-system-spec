# Requirements {#Reporting-Standardv1.0.0-Requirements}

| Epic Mapping | Requirement ID | Requirement Text | Level |
| --- | --- | --- | --- |
| Epic 1 | **GP-RR-1-01** | **Consume Data**  Ability to consume data items made available by other Capabilities to allow comprehensive reporting.  Support for all data items is not required and only a subset could be consumed dependent on the Solution that is being provided. | MUST |
| Epic 1 | **GP-RR-1-02** | **Query Data**  Consumed data items to be available for use by Practice staff when defining search criteria within reports.  Access to data is dependent on Role Based Access Control | MUST |
| Epic 1 | **GP-RR-1-03** | **Provide Information to NHS Digital**  Provide details to NHS Digital of the Capabilities that are fully supported in GP-RR-1-01. This is each Capability where all mandated data items for a that Capability are consumed to support reporting. | MUST |

# Capability {#Reporting-Standardv1.0.0-Capability}

**Applicable Capability**

All supplier Solutions will need to meet this Standard if they are delivering the Reporting Capability
