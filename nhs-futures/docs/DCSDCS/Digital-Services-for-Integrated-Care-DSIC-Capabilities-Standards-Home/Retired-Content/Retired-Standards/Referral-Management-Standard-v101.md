# Requirements  {#ReferralManagement-Standardv1.0.1-Requirements}

| Epic Mapping | Requirement ID | Requirement Text | Level |
| --- | --- | --- | --- |
| C11E1 | **GP-08.3-01** | **Support Referrals**  Support Referrals outside the Practice via a number of mechanisms (that can include interaction with software provided by other suppliers to provide a full Solution), including:   - eReferrals - Manual Referrals   Such mechanisms are to be invoked with the Patient in context (Demographic Information automatically obtained)  For further information see e-Referrals Service (e-RS) | MUST |
| C11E1 | **GP-08.3-02** | **Record referral information within Patient Record**  Record Referral information within the Patient Record:   - Unique identifier (this can be the Unique Booking Reference Number – UBRN used for eReferrals) - Date of Referral - Status - Priority - Referrer – Staff Member detail - Return correspondence addressee (default to referrer / requestor but amendable) - Recipient / target organisation - Recipient / target individual - Speciality - Service type (e.g. outpatient, direct access service, day case, inpatient) - Type/request item (as a coded clinical term) - Reason for the Referral - Sample ID (as applicable)   Data to be pulled from organisation data and/or national reference data (e.g. details for Staff Members) wherever possible.  See GP-08.3-01 for Referrals | MUST |
| C11E1 | **GP-REFM-03** | **Inter-provider transfer Administrative Minimum Data Set (ISB0112)**  Adhere to the Inter-provider transfer Administrative Minimum Data Set (ISB0112) Standard. | MUST |
| C11E2 | **GP-WF-5.1-04** | **Referrals Reporting**  Ability to generate a report on Referrals (list of Referrals with associated status by Referrer by Recipient Target (Service, Organisation and/or Individual) within a date range) | MUST |
