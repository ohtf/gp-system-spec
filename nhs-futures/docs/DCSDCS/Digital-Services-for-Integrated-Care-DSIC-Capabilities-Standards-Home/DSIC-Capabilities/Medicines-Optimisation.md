# Description {#MedicinesOptimisation-Description}

Enables Health or Care Professionals to review and request changes to a Patient's current medication.

# Outcomes {#MedicinesOptimisation-Outcomes}

|  |  |
| --- | --- |
| For a Patient: | Increased confidence that the Patient’s medication regimen ensures that they are taking the most appropriate and relevant combination of medication and prevent unnecessary medicines being prescribed. |
| For a Health or Care Professional: | The ability to make more informed decisions and request changes to a Patient’s medication based on a single, unified view of a Patient’s current medication. |
