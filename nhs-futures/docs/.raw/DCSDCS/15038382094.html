This accessibility statement applies to all content in this space.

This website is run by NHS England Digital Services for Integrated Care.

We want as many people as possible to be able to use this website. This means users should be able to:

  • Change colours, contrast levels and fonts.

  • Zoom in up to 200% without the text spilling off the screen.

  • Navigate most of the website using just a keyboard.

  • Navigate most of the website using speech recognition software.

  • Navigate the website using a screen reader (including the most recent versions of JAWS, NVDA and VoiceOver).

AbilityNet has advice on making your device easier to use if you have a disability.

How accessible this website is

We know from conducting accessibility audits that some parts of the site are not fully accessible. For example:

  • Some tables are not tagged to indicate to screen readers that they are for presentation only.

  • Elements of some tables can not be navigated by assistive technology.

  • Some content is unusable at a low resolution.

  • The expandable Help sidebar may not display correctly for screen readers or non-mouse users.

  • The social panel (containing reaction buttons) at the bottom of a page are not interactive when using assistive technology.

Feedback and contact information

  • If you have any problems accessing information or using this website.

  • If you have any positive feedback about the accessibility for this website.

Alternative formats

We have designed our content to be as accessible as possible.

If you need information on this website in a different format, like accessible PDF, large print, easy read, audio recording or Braille, please england.buying.catalogue@nhs.net.

We will review your request and get back to you in 2 weeks.

Technical information about the accessibility for this website

NHS England is committed to making its website accessible, in accordance with the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018.

Compliance status

The website has been tested against the Web Content Accessibility Guidelines (WCAG) 2.2 AA standard.

This website is partially compliant with the Web Content Accessibility Guidelines (WCAG) version 2.2 AA standard, due to the non-compliances listed below.

Non-compliance with the accessibility regulations

The content listed below is non-accessible for the following reasons.

  • We use tables to display some information relating to our Capabilities. We do not have the ability to add the necessary tag to indicate to screen readers that these are presentation tables. This fails WCAG 2.2 success criterion 1.3.1 Info and Relationships (Level A) [info-and-relationships].

As we can’t add the tag, we are in the process of agreeing a new design for the tables, so that we can replace them with an accessible format.

  • The reaction buttons on the site do not convey being disabled to screen readers. This fails WCAG 2.2 success criterion 4.1.2 Name, Role, Value (Level A) [name-role-value].

We are currently retesting this issue to understand how it can be fixed.

Disproportionate burden

The content listed below falls under what we believe to be a disproportionate burden within the meaning of the accessibility regulations. This is because at the moment we do not have access to a competing system for hosting this content, and the issues listed below must be fixed by our supplier. We have raised the accessibility issues with our supplier and are working with them to resolve the issues. We also have plans to look at potential other suppliers who may be more accessible.

  • A click event is incorrectly applied to a table header, being used to sort the column. There is no visual indicator of its presence, and it cannot be accessed via the tab key. This fails WCAG 2.2 success criterion 1.3.1 Info and Relationships (Level A) [info-and-relationships] and 4.1.2 Name, Role, Value (Level A) [name-role-value].

  • Where "Copy link to heading" is used, there is no text alternative. This fails WCAG 2.2 success criterion 1.3.3 Sensory Characteristics (Level A) [sensory-characteristics].

  • When content is viewed at 100% zoom, it doesn’t render well enough. This fails WCAG 2.2 success criterion 1.4.10 Reflow (Level AA) [reflow].

  • The expandable Help bar is focused after the entire page content and not directly after opening the menu. This fails WCAG 2.2 success criterion 2.4.3 Focus Order (Level A) [focus-order].

  • When the user activates the "Show more" button in the list of help articles, the focus remains on the button, which is at the bottom of the list. This fails WCAG 2.2 success criterion 1.4.13 Content on Hover or Focus (Level AA) [content-on-hover-or-focus] and 2.4.3 Focus Order (Level A) [focus-order].

  • An invisible input is focusable via the keyboard when no controls are present. This fails WCAG 2.2 success criterion 2.4.3 Focus Order (Level A) [focus-order] and 2.4.3 Focus Order (Level A) [focus-order].

  • The "Copy link to heading" button is smaller than the required on some headings.

What we are doing to improve accessibility

At NHS England, creating accessible services is a team effort. We want our teams to make accessible services by:

  • Using a library of accessible components and patterns.

  • Carrying out regular accessibility audits and testing.

  • Designing and building to level AA of WCAG 2.2.

We are making sure that accessibility issues highlighted in this statement are being prioritised and fixed. Measures include:

  • Ongoing improvements to the NHS England Digital Services for Integrated Care design principals with a focus on accessibility.

  • Working with suppliers to improve the accessibility of their products.
