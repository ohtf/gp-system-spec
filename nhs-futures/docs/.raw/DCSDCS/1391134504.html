Description

Supports Patient/Service User health and care information being brought together in a single consolidated record.

Outcomes

For a Patient/Service User:

Removes the need to repeat their previously reported health and care information when they are seen by Health or Care Professionals and receive improved care because the Health or Care Professionals treating them are fully informed.

For a Health or Care Professional:

View a complete and up to date Unified Care Record for a Patient/Service User with health and care information gathered from different systems from a variety of health and care settings into a single record. Enables them to assess and treat the Patient/Service User more safely and effectively and can enable more integrated care across organisational boundaries through access to a common and shared view of the Patient/Service User's health and care information.

MUST Epics - Describes the minimum functionality required to deliver a Capability. Solutions MUST be successfully evaluated against each Epic and Acceptance Criteria via Capability Assessment in order to be associated with this Capability

E00736 - view Unified Care Record

As a Health or Care Professional

I want to view Unified Care Records for Patients/Service Users

So that I can get a comprehensive view of Patients/Service Users' health and care information

Acceptance criterion 1: view Unified Care Records

Given the Health or Care Professional is permitted to view Unified Care Records

When the Health or Care Professional selects to view a Patient/Service User’s Unified Care Record

Then the Unified Care Record is displayed

Acceptance criterion 2: view source of Unified Care Record information

Given the Health or Care Professional is permitted to view Unified Care Records

When the Health or Care Professional selects to view the source of a Unified Care Record’s information

Then the source of the Unified Care Record’s information is displayed

E00737 - Patient/Service User views Unified Care Record

As a Patient/Service User

I want to view my Unified Care Record

So that I am assured that my health and care information is correct and complete in my Unified Care Record

Acceptance criterion 1: Patient/Service User views Unified Care Records

Given the Patient/Service User is permitted to view Unified Care Records

When the Patient/Service User selects to view their Unified Care Record

Then the Unified Care Record is displayed

E00738 - configure default Unified Care Record views

As a Health or Care Professional 

I want to configure default views for Unified Care Records

So that I can immediately access the right information to support the health or care-related task I am undertaking

Acceptance criterion 1: configure default Unified Care Record views

Given the Health or Care Professional is permitted to manage Unified Care Records

When the Health or Care Professional selects to configure the default view of Unified Care Records

Then the default view is configured

E00738 - Supporting Information

  • Examples of configuration MAY include, but are not limited to:

    • Create a default Unified Care Record view

    • Amend a default Unified Care Record view

    • Enable a default Unified Care Record view

    • Disable a default Unified Care Record view
