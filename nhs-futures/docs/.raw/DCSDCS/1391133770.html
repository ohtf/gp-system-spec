Description

Supports the recording of Requests for Investigations information for Patients. Investigation results can also be received, reviewed and stored against the Electronic Patient Record (EPR).

Outcomes

For a Patient:

Improving the accuracy and speed of test requests and results between care settings leading to accurate diagnosis, shorter waiting times for Appointments and access to appropriate treatment.

For Healthcare Organisations:

Able to record, update and view details of all requests. Investigation results can be received, reviewed and stored against the Electronic Patient Record (EPR) ensuring up to date and relevant information is available to appropriate staff to support timely Patient care.

MUST Epics - Describes the minimum functionality required to deliver a Capability. Solutions MUST be successfully evaluated against each Epic and Acceptance Criteria via Capability Assessment in order to be associated with this Capability

E00432 - manage Requests for Investigations information for Patients

As a Health or Care Professional

I want to manage Requests for Investigations information for Patients

So that information relating to Requests for Investigations for Patients is managed

Acceptance criterion 1: create Requests for Investigations information in the Patient’s Electronic Patient Record (EPR)

Given the Health or Care Professional is permitted to manage Requests for Investigations information

When the Health or Care Professional selects to create a Request for Investigations information for a Patient

Then the Request for Investigations information is created in the Patient’s Electronic Patient Record (EPR)

And the date of the Request for Investigations is recorded

And the requestor is recorded

And the request type is recorded as a coded clinical term

And the reason for the request is recorded

And the sample type is recorded

And the laboratory name is recorded

Acceptance criterion 2: view Request for Investigations information

Given the Health or Care Professional is permitted to manage Requests for Investigations information

When the Health or Care Professional selects to view Request for Investigations information for a Patient

Then the Request for Investigations information is displayed

Acceptance criterion 3: amend Request for Investigations information

Given the Health or Care Professional is permitted to manage Requests for Investigations information

When the Health or Care Professional selects to amend Request for Investigations information for a Patient

Then the Request for Investigations information is amended

Acceptance criterion 4: delete Request for Investigations information

Given the Health or Care Professional is permitted to manage Requests for Investigations information

When the Health or Care Professional selects to delete Request for Investigations information for a Patient

Then the Request for Investigations information is deleted

E00432 - Supporting Information

  • Requests for Investigations are typically made using a separate Solution, but information about the request and that it has happened, needs to be recorded in the Patient’s Electronic Patient Record (EPR)

  • Examples of Requests for Investigations MAY include, but are not limited to:

    • Pathology requests

    • Radiology requests

    • Electrocardiogram (ECG) requests

    • Electroencephalogram (EEG) requests

    • Echocardiogram (Echo) requests

    • Lung Function requests

  • See Data Standards for further information on Clinical Codes and terms

E00434 - reconcile Investigation Results with Requests for Investigations information

As a Health or Care Professional

I want to reconcile received Investigation Results with existing Requests for Investigations information

So that I can identify outstanding Requests for Investigations for Patients

Acceptance criterion 1: reconcile Requests for Investigations with Investigation Results

Given the Health or Care Professional is permitted to reconcile Investigation Results with Requests for Investigations information

And Investigation Results have been received for a Patient

When the Health or Care Professional selects to reconcile the Investigation Results with a Request for Investigations for the Patient

Then the Request for Investigations is reconciled with the Investigation Results

E00434 - Supporting Information

  • The data items available when reconciling Investigation Results with Request for Investigations information MAY include, but are not limited to:

    • Date of request

    • Requestor

    • Request type, as a coded clinical term

    • Reason for the request

    • Sample type

    • Laboratory name

  • See Data Standards for further information on coded clinical terms
