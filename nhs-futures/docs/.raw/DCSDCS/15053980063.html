Description

Enables Health or Care Professionals to appropriately process and respond to Online Patient/Service User Consultations using a pre-configured Care Navigation Workflow.

Outcomes

For a Patient/Service User:

Consistent user experience of requesting assistance using Online Consultation tools.

For Primary Care:

Ability to process Online Consultation requests using pre-configured Workflow.

Enable the Health or Care Organisation to respond to Online Consultations efficiently.

Enable navigating the Online Patient/Service User Consultations and Requests to the right Health or Care Professional in a multidisciplinary team.

For the wider NHS and social care system:

Enable consistent processing of Online Patient/Service User Consultations and Requests.

E00549 - configure Care Navigation Workflow

As a Health or Care Professional

I want to configure Care Navigation Workflows

So that I can control the processing of Online Consultation requests from Patient/Services Users for the Healthcare Organisation

Acceptance criterion 1: configure Care Navigation Workflow

Given the Health or Care Professional is permitted to configure Care Navigation Workflows

Then the Care Navigation Workflow is configured

Acceptance criterion 2: view Care Navigation Workflow

Then the details of the selected Care Navigation Workflow are displayed

Acceptance criterion 3: disable Care Navigation Workflow

Given the Health or Care Professional is permitted to disable Care Navigation Workflows

When the Health or Care Professional selects to disable a Care Navigation Workflow

Then the selected Care Navigation Workflow is disabled

Acceptance criterion 4: enable Care Navigation Workflow

Given the Health or Care Professional is permitted to enable Care Navigation Workflows

When the Health or Care Professional selects to enable a Care Navigation Workflow

Then the selected Care Navigation Workflow is enabled

E00549 - Supporting Information

  • A Care Navigation Workflow can be described as:

    • A pre-configured pathway of events to be completed by one or more Health or Care Professionals or Organisations, to process an episode of care. It MAY include some or all the following and more:

      • Receive structured or semi-structured request from Patient/Service User

      • Filter the information manually or based on predefined rules

      • Ability to refer or signpost the request to different services or appropriate Health or Care Professionals either manually or based on predefined rules

      • Assessment of the request either by a human or system based on predefined rules or automated tool

    • These Workflows can be manual or automated or a mix of both

  • Examples of configuring a Care Navigation Workflow MAY include, but are not limited to:

    • Create a new Care Navigation Workflow

    • Amend an existing Care Navigation Workflow

  • Examples of details of a Care Navigation Workflow MAY include, but are not limited to:

    • Tasks involved in a Care Navigation Workflow

    • Decision points in a Care Navigation Workflow

    • Various actors/resources involved in a Care Navigation Workflow

    • Routing of Online Consultation requests to specific team or roles
