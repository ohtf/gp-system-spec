C10E1GP-PF-5

Report for Future Extraction

Suppliers to provide reports which detail the Patients who are to be included in an upcoming national extraction. This enables the GP Practice Users to see which Patients will be included in the counts for national extractions.

Upcoming extracts are extracts which have been certified by GPES and have an associated set of Run Time Parameters. It is the responsibility of the GPES team to provide correct Run Time Parameters to Suppliers.

For more information on 'upcoming extracts' and those that have 'extract parameter' values, see GPES Data Extraction

GP-PF-5.2.2

National Extraction Reports - Identifier and Relevant Information

The report to identify the Patients by their NHS Number and should provide other information relevant to the extraction and the logical steps of the 'Business Rules'.

Click here to see High level User Story for definition of 'other information'
As a GP Practice User, I want to see the data that has led a Patient to be selected into the report, So that I can determine why a Patient has been included in an extract.
Given that a set of parameters, which are defined in the business rules, must be met
When a Patient is successfully selected and included in an extract
Then the parameters and the associated data that have been met should be available in the report.
For example:
Rule 1: Patient must be registered at the practice
Rule 2: patient must be over 65
Rule 3: patient must be male
Rule 4: patient must have either code x y or z between date a and b

The report should contain:
  • the registration status
  • the Patient's age
  • the Patient's gender
  • the code and the date which has led to selection

GP-PF-6

Report for Previous Extractions

An additional version of the reports defined in GP Extracts Verification - Standard#GP-PF-5.2, GP Extracts Verification - Standard#GP-PF-5.2.1, GP Extracts Verification - Standard#GP-PF-5.2.2 and GP Extracts Verification - Standard#GP-PF-5.2.3 to be made available which meets the same requirements so that Practice Users can see precisely which Patients have been included or not in the extractions which have been executed.

These reports need to be accessible throughout the duration of the service and then for 6 years from the end of the service. The duration of the service is defined in the appropriate service specification or via the GMS contract (GMS Statement of Financial Entitlements 2013, section 25.12)

See the Pneumococcal vaccination specification - Paragraph 2.2 states that the Service is valid from 01 April 2017 to 31 March 2018 and Paragraph 7.6 part iv. states that there is a maximal 6 month claim window.

See Current Live Extract Specifications section for information on current live extracts and which are defined as payment extracts.

C10E1GP-PF-7

Search for Inclusion/Exclusion Reason

Practice Users to have ability to search against individual Patient Records to identify the reason for that Patient being included or excluded in/from a national extract.

C10E1GP-PF-7.1

Search Before and After Extraction

Practice Users to be able to conduct the search prior to an extract being run and identify if a Patient is included or excluded and the reason why.

After a national extraction has been run the Practice User to be able to search the record and identify why a Patient was excluded or included in a specific extract for a specific period.

C10E1GP-PF-7.1.1

Search Result Updated

If the Patient Record is updated, the result of the search to reflect the change if:

- The national extract has not yet been run
- The national extract is due to be re-run

If data has been re-sent via the national extraction system, the result of the search to reflect the data that was originally sent and the data that was re-sent.

Changes made to the Patient Record will be reflected in the associated reports/searches.

See GPIT Futures Detailed Requirements Requirement 7.1.1 Supporting Diagram v2.0.pdf which shows how search results should be stored.

C10E1GP-PF-7.2

Search Result Content

When conducting the search in GP Extracts Verification - Standard#GP-PF-7.1.2:

- The Search and associated Reason to match exactly the extraction logic as set out in the 'Business Rules' (as per requirement GP Extracts Verification - Standard#GP-PF-5.2)
- The Search and associated Reason to identify the stage in the extraction logic and the reason for the Patient being excluded or included (related to requirement GP Extracts Verification - Standard#GP-PF-5.2.1)
- The Search and associated Reason to provide additional relevant information to the logical steps which identifies why the Patient has been excluded or included (as per requirement GP Extracts Verification - Standard#GP-PF-5.2.2)
-The Reason to be provided as a plain English description of why the Patient has been excluded or included (as per requirement GP Extracts Verification - Standard#GP-PF-5.2.3)
