Introduction 

SEFT is an Authority implementation of Tibco's MFT (Managed File Transfer) product. It is used as the transport mechanism in a number of different interfaces. Additional information about SEFT and a quick help guide are available at The Authority's website.

Documentation

The 3rd party set up guide is intended to give a step-by-step guide to setting up a Secure File Transfer Protocol (SFTP) transfer from a Windows platform (server or desktop) using freely available tools from the internet: 3rd Party Set Up.docx
