Description

Enables Health or Care Professionals to review and request changes to a Patient's current medication.

Outcomes

For a Patient:

Increased confidence that the Patient’s medication regimen ensures that they are taking the most appropriate and relevant combination of medication and prevent unnecessary medicines being prescribed.

For a Health or Care Professional:

The ability to make more informed decisions and request changes to a Patient’s medication based on a single, unified view of a Patient’s current medication.

MUST Epics - Describes the minimum functionality required to deliver a Capability. Solutions MUST be successfully evaluated against each Epic and Acceptance Criteria via Capability Assessment in order to be associated with this Capability

E00739 - view current medication for Patients

As a Health or Care Professional

I want to view current medication for Patients

So that I have a complete view of their current medication and can make more informed decisions

Acceptance criterion 1: view current medication for Patients

Given the Health or Care Professional is permitted to view current medication for Patients

When the Health or Care Professional selects to view current medication for a Patient

Then the current medication for the Patient is displayed

E00739 - Additional Implementation Details

Solutions MUST comply with the following when implementing this Epic:

  • Solutions which integrate with the GP Core Clinical Solution to utilise one of the below interfaces:

    • GP Connect Access Record HTML Standard (Consumer requirements)

    • GP Connect Access Record Structured Standard (Consumer requirements)

E00739 - Supporting Information

  • Information about current medication for Patients MAY be obtained from one or more Solutions

  • Examples of current medication MAY include, but are not limited to:

    • Medication issued by the Healthcare Organisation

    • Medication not issued by the Healthcare Organisation

    • Over the counter food supplements

E00740 - request changes to current medication for Patients

As a Health or Care Professional

I want to request changes to current medication for Patients

So that I can ensure that medication regimens for Patients are appropriate

Acceptance criterion 1: create requests to change current medication for Patients

Given the Health or Care Professional is permitted to manage requests to change current medication for Patients

When the Health or Care Professional selects to create a request to change current medication for a Patient

Then the request to change the current medication for the Patient is created

E00740 - Supporting Information

  • Examples of requests to change current medication for Patients MAY include, but are not limited to:

    • Dosage Information

    • Medication substitution

E00742 - manage Patient medication regimen review notification rules

As a Health or Care Professional

I want to manage Patient medication regimen review notification rules

Acceptance criterion 1: create notification rules for Patient medication regimen reviews

Given the Health or Care Professional is permitted to manage notification rules for Patient medication regimen reviews

E00746 - view warnings for medications

As a Health or Care Professional

I want to view warnings for medications

So that I can determine if a medication is appropriate to be prescribed for a Patient

Acceptance criterion 1: view warnings for medications

Given the Health or Care Professional is permitted to view warnings for medications

When warnings for a medication are triggered

Then Interactions with other current medication warnings are displayed

And Active ingredients duplication warnings are displayed

And inappropriate prescribing warnings are displayed

E00746 - Supporting Information

    • Requesting a change to a Patient’s current medication

    • Viewing a medication
