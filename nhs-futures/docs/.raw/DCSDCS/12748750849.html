Full or Partial Capability status. For this Capability, Solutions are required to meet a minimum of one MUST EPIC and associated acceptance criteria but not all MUST EPICs (where there are multiple MUST EPICS) to achieve Partial Capability Status, or; to meet all MUST EPICs and their associated acceptance criteria to achieve Full Capability Status.

Description

Supports clinical decision-making to improve Patient safety at the point of care.


Outcomes

For a Patient:Clinicians are able to make better informed and safer care decisions, resulting in increased patient confidence in overall care provided.
For General Practice:The provision of flexible tools that assist clinicians in making informed healthcare decisions for their patients, in order to reduce costs and provide high quality care and support delivered in a safe way.
For the wider NHS and social care system:Better informed decisions leading to more appropriate Referrals and implementation of appropriate care pathways across a wide variety of settings.


MUST Epics - Epics and acceptance criteria will be evaluated during the Capability Assessment Stage of Onboarding

C6E1 - access to Clinical Decision Support

As a Practice User

I want access to Clinical Decision Support

So that I have Clinical Decision Support

Acceptance criterion 1: access to Clinical Decision Support

Given the Practice User is permitted to use Clinical Decision Support

When Clinical Decision Support is triggered

Then they can have Clinical Decision Support

Acceptance criterion 2:  Clinical Decision Support audit 

Given the Practice User is permitted to use Clinical Decision Support

And a Decision has been recorded

When the Practice User views previous decisions made with Clinical Decision Support

Then the authority of the decision is displayed

And the reasons for the decision is displayed

And the source documentation used is displayed

And the criteria used is displayed

Acceptance criterion 3: view Clinical Decision Support tool version history

Given the Practice User is permitted to use Clinical Decision Support

When the Practice User chooses to view the Clinical Decision Support tool version history

Then the Clinical Decision Support tool version history is displayed

And the source documentation used is displayed

And the criteria used is displayed

And date and time of update is displayed


C6E2 - local configuration for Clinical Decision Support triggering

As a Practice User

I want to configure Clinical Decision Support triggering

So that the rules for Clinical Decision Support triggering are applied

Acceptance criterion 1: configure Clinical Decision Support triggering by Staff Member

Given the Practice User is permitted to configure Clinical Decision Support triggering

When the Practice User chooses to configure Clinical Decision Support triggering by Staff Member

Then the configuration is applied to the Staff Member

Acceptance criterion 2: configure Clinical Decision Support triggering by staff role

Given the Practice User is permitted to configure Clinical Decision Support triggering

When the Practice User chooses to configure Clinical Decision Support triggering by staff role

Then the configuration is applied to the staff role

Acceptance criterion 3: enable triggering of tools

Given the Practice User is permitted to configure Clinical Decision Support 

When the Practice User chooses to enable triggering of an individual tool

Then the triggering of a tool is enabled

Acceptance criterion 4: disable triggering of tools

Given the Practice User is permitted to configure Clinical Decision Support 

When the Practice User chooses to disable triggering of an individual tool

Then the triggering of a tool is disabled


C6E3 - view Clinical Decision Support reports

As a Practice User

I want to view Clinical Decision Support reports 

So that I can view reports on Clinical Decision Support 

Acceptance criterion 1: view Clinical Decision Support reports

Given the Practice User is permitted to view Clinical Decision Support reports 

When the Practice User chooses to view a Clinical Decision Support report 

Then the report is displayed 


MAY Epics - All May Epics and Acceptance Criteria will be evaluated during the Capability Assessment Stage of On-boarding. Any May Epics that are assessed as met will be available to buyers via the Buying Catalogue.

C6E4 - configuration for custom Clinical Decision Support

As a Practice User

I want to configure custom Clinical Decision Support 

So that the rules for custom Clinical Decision Support are applied

Acceptance criterion 1: configure custom Clinical Decision Support 

Given the Practice User is permitted to configure Clinical Decision Support 

When the Practice User chooses to configure custom Clinical Decision Support 

Then the configuration is applied
