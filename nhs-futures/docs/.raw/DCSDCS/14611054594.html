Introduction

The Vaccination Extract Standard specifies the flow of vaccination-related information from healthcare settings to the Authority.

Requirements

Applicable Suppliers

ID

Requirement

Level

GP Suppliers

VE01

Implement and maintain the extraction of vaccination information inline with the latest NHSE Daily Vaccination Events (In-Bound) Extract specification version.

The following vaccination extracts to be supported on a daily basis:

  • Influenza (Flu)

  • Respiratory Syncytial Virus (RSV)

  • Human Papillomavirus (HPV)

  • 3 in 1

  • MenACWY

The following vaccination extracts to be supported on a daily or weekly basis:

  • Measles, Mumps, Rubella (MMR) Vaccination data to be provided for Patients from 1 to 25 years old
