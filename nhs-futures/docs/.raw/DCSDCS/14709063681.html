Description

Supports the conversion of speech to unstructured text and the recording of this unstructured text to Patient/Service User’s record.

Outcomes

For a Patient/Service User:

Accurate recording to a Patient/Service User's record of information based on Patient/Service User interactions, supporting more accurate and efficient care provision.

For Health or Care Organisations:

Time savings and better staff productivity with accuracy and efficiency as part of the process for recording information for Patient/Service User interactions. 

MUST Epics - Describes the minimum functionality required to deliver a Capability. Solutions MUST be successfully evaluated against each Epic and Acceptance Criteria via Capability Assessment in order to be associated with this Capability

E00256 - convert speech to unstructured text

As a Health or Care Professional

I want speech to be converted to unstructured text

So that interactions with Patient/Service Users are captured more efficiently using speech converted to unstructured text

Acceptance criterion 1: speech is converted to unstructured text

Given the Health or Care Professional is permitted to manage the conversion of speech to unstructured text

When the Health or Care Professional selects to convert speech to unstructured text

Then the speech is converted to unstructured text

Acceptance criterion 2: view unstructured text

Given the Health or Care Professional is permitted to manage the conversion of speech to unstructured text

When the Health or Care Professional selects to view the unstructured text that has been converted from speech

Then the unstructured text is displayed

E00256 - Supporting Information

  • Examples of converting speech to unstructured text MAY include, but are not limited to:

    • Converting live speech captured by a microphone

    • Converting pre-recorded speech captured in an audio file

    • Converting pre-recorded speech captured in a video file

E00707 - record unstructured text to the Patient/Service User’s record

As a Health or Care Professional

I want to record unstructured text to the Patient/Service User’s record

So that a complete history of the Patient/Service User’s encounters can be maintained

Acceptance criterion 1: record unstructured text to the Patient/Service User’s record

Given the Health or Care Professional has converted speech to unstructured text using Digital Dictation

When the Health or Care Professional selects to record unstructured text to a Patient/Service User’s record

Then the unstructured text is recorded to the Patient/Service User’s record

E00707 - Additional Implementation Details

    • IM1 - Interface Mechanism Standard (Practice Consumer requirements)
