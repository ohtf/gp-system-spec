Description

Supports the Health or Care Professional in managing Patient/Service User's Cases and Caseloads.

Outcomes

For a Health or Care Professional:

The ability to create and manage a collection of Cases and Caseloads for Patients/Service Users.

For Health or Care Organisations:

The ability to manage Health or Care Professional resourcing based on Patient/Service User Cases and Caseloads.

MUST Epics - Describes the minimum functionality required to deliver a Capability. Solutions MUST be successfully evaluated against each Epic and Acceptance Criteria via Capability Assessment in order to be associated with this Capability

E00728 - manage Cases for Patients/Service Users

As a Health or Care Professional

I want to manage Cases for Patients/Service Users

So that I can manage the care needs of Patients/Service Users

Acceptance criterion 1: create Cases for Patients/Service Users

Given the Health or Care Professional is permitted to manage Cases for Patients/Service Users

When the Health or Care Professional selects to create a Case for a Patient/Service User

Then the Case is created for the Patient/Service User

Acceptance criterion 2: view Cases for Patients/Service Users

Given the Health or Care Professional is permitted to manage Cases for Patients/Service Users

When the Health or Care Professional selects to view a Case for a Patient/Service User

Then the Case for the Patient/Service User is displayed

Acceptance criterion 3: amend Cases for Patients/Service Users

Given the Health or Care Professional is permitted to manage Cases for Patients/Service Users

When the Health or Care Professional selects to amend a Case for a Patient/Service User

Then the Case is amended for the Patient/Service User

Acceptance criterion 4: close Cases for Patients/Service Users

Given the Health or Care Professional is permitted to manage Cases for Patients/Service Users

When the Health or Care Professional selects to close a Case for a Patient/Service User

Then the Case is closed for the Patient/Service User

E00728 - Supporting Information

  • Examples of Cases MAY include, but are not limited to:

    • Incoming Referrals

    • Service Requests
